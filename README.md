# 🎓 EduOutcome AI
### AI-Powered Educational Outcome Planning and Course Design

EduOutcome AI is a web-based educational platform designed to support faculty in course planning, Outcome-Based Education (OBE), CO–PO mapping, assessment design, Bloom's Taxonomy, and academic reporting.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/geethugmpk/EduOutcome-AI.git
cd EduOutcome-AI
```

Install dependencies:

```bash
python -m pip install -r flask_app/requirements.txt
```

Start the Flask application:

```bash
python flask_app/app.py
```

Open `http://127.0.0.1:5000/` in your browser.
